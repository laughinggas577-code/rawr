========================================
  Rawr Automation - Build Instructions
========================================

REQUIREMENTS:
  - Java 21 (JDK 21)
  - Internet connection (to download NeoForge dependencies)

QUICK BUILD (2 steps):
  1. Open a terminal in the project folder
  2. Run:
       Windows:  gradlew.bat build
       Linux:    ./gradlew build

  The built mod jar will be at: build/libs/RawrAutomation-2.0.0.jar

INSTALL:
  1. Install NeoForge for Minecraft 1.21.1
  2. Copy RawrAutomation-2.0.0.jar to your .minecraft/mods/ folder
  3. Launch Minecraft with the NeoForge 1.21.1 profile

IN-GAME USAGE:
  /rawr                    - Show help and all modules
  /rawr list               - List modules and status
  /rawr toggle automine    - Toggle AutoMine
  /rawr toggle autoeat     - Toggle AutoEat
  /rawr toggle autofish    - Toggle AutoFish (hold a fishing rod)
  /rawr toggle autofarm    - Toggle AutoFarm
  /rawr toggle autoattack  - Toggle AutoAttack
  /rawr walkto X Y Z       - Auto-walk to coordinates
  /rawr attack animals     - Toggle animal targeting

MODULES:
  AutoMine   - Mines blocks you look at automatically
  AutoEat    - Eats food when hunger drops below 80%
  AutoFish   - Auto-reels and recasts fishing rod
  AutoFarm   - Harvests mature crops and replants
  AutoAttack - Attacks hostile mobs within reach
  PathWalker - Walks to specified coordinates
