========================================
  Rawr Automation - Build Instructions
========================================

REQUIREMENTS:
  - Java 8 (JDK 1.8) - MUST be Java 8, newer versions won't work
  - Internet connection (to download Forge dependencies)

QUICK BUILD (3 steps):
  1. Extract this source zip to a folder
  2. Open a terminal in that folder
  3. Run:
       Windows:  gradlew.bat setupDecompWorkspace && gradlew.bat build
       Linux:    ./gradlew setupDecompWorkspace && ./gradlew build

  The built mod jar will be at: build/libs/RawrAutomation-1.0.0.jar

INSTALL:
  1. Install Minecraft Forge 1.8.9 (11.15.1.2318)
  2. Copy RawrAutomation-1.0.0.jar to your .minecraft/mods/ folder
  3. Launch Minecraft with the Forge 1.8.9 profile

IN-GAME USAGE:
  /rawr              - Show help and all modules
  /rawr list         - List modules and status
  /rawr automine     - Toggle AutoMine
  /rawr autoeat      - Toggle AutoEat
  /rawr autofish     - Toggle AutoFish (hold a fishing rod)
  /rawr autofarm     - Toggle AutoFarm
  /rawr autoattack   - Toggle AutoAttack
  /rawr walkto X Y Z - Auto-walk to coordinates
  /rawr attack animals - Toggle animal targeting

MODULES:
  AutoMine   - Mines blocks you look at automatically
  AutoEat    - Eats food when hunger drops below 80%
  AutoFish   - Auto-reels and recasts fishing rod
  AutoFarm   - Harvests mature crops and replants
  AutoAttack - Attacks hostile mobs within reach
  PathWalker - Walks to specified coordinates
